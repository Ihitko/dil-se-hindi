# Dil Se Hindi

Learn Hindi for the one you love: lessons in 5 stages, stories, conversation scenes, verb, number and time gyms, love notes, and spaced repetition.

**Install on iPhone:** open https://ihitko.github.io/dil-se-hindi/ in Safari, tap Share, then Add to Home Screen.

Works offline. Progress is stored on your device; use Profile → Move your progress to copy it between devices.
